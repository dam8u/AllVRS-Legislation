# AllVRS Legislation

Legislative research, analysis, and draft bill language for the Joint Leadership
Council of Veterans Service Organizations (JLCVSO), concerning the Virginia
Retirement System (Title 51.1, Code of Virginia).

## Document formats

Briefs are authored in Markdown, which is the source of record. Every brief also
has an editable `.docx` alongside it, generated by [tools/md_to_docx.py](tools/)
and checked figure-by-figure against its source — see [tools/README.md](tools/README.md).
Hand-edits to a `.docx` are lost on the next rebuild; change the `.md` and regenerate.

## Conventions

- All statutory citations are verified against the Code of Virginia on
  [law.lis.virginia.gov](https://law.lis.virginia.gov/) with the retrieval date recorded.
- Facts, analytic assumptions, recommendations, and draft bill language are kept
  visibly distinct. Analyst estimates are never presented as VRS or actuarial figures.
- Each brief carries a fiscal assumption register and a claim/evidence table.
- "Service credit," "creditable service," "earned service," "active service," and
  "benefit-calculation service" are not treated as interchangeable. Each term's
  statutory meaning is established before it is relied on.
